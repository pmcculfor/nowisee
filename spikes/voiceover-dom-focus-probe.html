How to run this on iPhone

  1. Open this page in Safari.
  2. Turn VoiceOver on (Settings → Accessibility → VoiceOver, or triple-click Side Button if set up).
  3. Use explore by touch: drag one finger slowly over the probes. Or swipe right / left to move VoiceOver from item to item.
  4. Do not double-tap unless you want to also test activation — the point of this page is focus-only.
  5. Watch (or listen to) the sticky status box at the top. It announces every time a real DOM focus event fires.
