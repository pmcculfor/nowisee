Nowisee screen reader probe

This page answers one question: when a screen reader is running, do the arrow keys actually reach a web page, and does the page's text get read aloud when it changes? Nowisee's whole design depends on both being true, so it is worth finding out before anything is built.

You do not need to know anything about the code to run this. Follow the steps, answer a few yes/no questions, and copy the summary at the bottom.

How to run the test

  1. Turn on your screen reader (NVDA, JAWS, VoiceOver, TalkBack — whichever you use).
  2. Pick a setup from the buttons below. There are six. Each one arranges the page differently; the point of the test is to find out which one behaves best.
  3. Press the “Put me in the reading area” button. This moves your focus into the box being tested.
  4. Press the Down arrow a few times, then Up, then Right, then Left. The text in the box is supposed to change every time, and your screen reader is supposed to read the new text.
  5. Read the Result section. It tells you, automatically, whether your key presses reached the page at all.
  6. Answer the questions under What did you hear? — only you can judge those.
  7. Repeat for each of the six setups.
  8. Copy the Summary text box at the bottom and send it back.

If the text never changes and the Result says nothing arrived, that is not a broken page — that is the finding. It means your screen reader is keeping the arrow keys for itself, and Nowisee will need a different arrangement. Move on to the next setup.
